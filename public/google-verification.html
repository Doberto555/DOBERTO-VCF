DOBERTO VCF Privacy Policy
GOOGLE OAUTH VERIFICATION

Reviewer navigation guide

This page is provided to help the Google Third-Party Data Safety review team test the production-ready Google OAuth and Google Contacts functionality in DOBERTO VCF.

Production domain: dobertovcf.online Authentication: Google OAuth Google Contacts: Optional No local password required

Requested Google scopes

DOBERTO VCF requests only the scopes needed for the user-facing features below.

openid email profile https://www.googleapis.com/auth/contacts

The contacts scope is requested separately from basic Google Sign-In and only when the user chooses to connect Google Contacts.

Why Contacts write access is required

DOBERTO VCF uses Google People API to create DOBERTO VCF network contacts directly in the authenticated user's Google Contacts account. A read-only Contacts scope cannot provide this write functionality.

The application does not use this scope for Gmail, Google Drive, Google Calendar, advertising, or unrelated purposes.

Step-by-step review instructions

  1. Open dobertovcf.online and choose registration/sign-in.
  2. Sign in with a Google account.
  3. Complete the DOBERTO VCF member registration if the account is not already registered.
  4. Open the Google Contacts section.
  5. Select Connect Google Contacts.
  6. On Google's OAuth consent screen, expand “4 services” / “Show all services” so every requested permission is visible and readable.
  7. Approve the requested permission.
  8. Enable Auto-Sync or, where available, select Sync now.
  9. Open Google Contacts using the same Google account and verify that DOBERTO VCF network contacts were created.

Test credentials

No local application username or password is required. DOBERTO VCF uses Google OAuth for authentication.

The reviewer may use an authorized Google test/reviewer account to complete the OAuth consent flow. No phone verification, credit card, or local password gate is required by DOBERTO VCF for Google OAuth testing.

Google user data used

  • Google account identifier, display name, verified email and profile picture for sign-in/account association.
  • OAuth access/refresh tokens and granted-scope metadata for the optional Google Contacts integration.
  • Connection/synchronization status, timestamps and error state required to operate Auto-Sync.

Security, retention and deletion

  • Google OAuth tokens are stored server-side and encrypted before database storage.
  • Production traffic and Google API calls use HTTPS/TLS.
  • Google user data is not sold or shared with advertisers.
  • Users can disable Auto-Sync and revoke Google access at any time.
  • Verified deletion requests are processed according to the published Privacy Policy.
